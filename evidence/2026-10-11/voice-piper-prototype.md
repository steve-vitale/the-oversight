# Piper TTS voice prototype (2026-10-11)

**Commit:** 936871e8 [needs-eyes] — merged locally, pending ship.

## What was built
- `src/js/voice-piper.js` (new, @ontology `voice-piper`): spoken villager dialogue via Piper TTS in-browser (`@mintplex-labs/piper-tts-web` 1.0.4, ONNX Runtime Web + espeak-ng WASM, MIT voices).
- **Voice classes:** 4 lazy-loaded packs, never in the base bundle — m-young (`en_US-ryan-medium`), m-old (`en_US-lessac-medium`), f-young (`en_US-amy-medium`), f-old (`en_US-kristin-medium`). Downloaded per speaker on first use, cached in Origin Private File System.
- **Deterministic profiles:** `Game.voiceProfileFor(person)` — pure function of the person record (sex × ageBand<35/35+, id+name hash jitter ±5% pitch / ±6% rate, temperament nudges). Same villager always sounds like themselves; 50/50 determinism proven.
- **Hook:** `sayLine()` in conversation.js calls `Game.convoSpeakLine(vid, chunk, opts)` per NPC beat. Gates: off (setting) → muted → locked (no user gesture yet) → foreign-skip → speaking-piper / speaking-fallback.
- **Playback:** `Game.audio.playVoice(blob, {pitch})` added to the existing Web Audio graph in app.js — one unlock flow, one mute, new line supersedes the last (never queues speech).
- **Settings:** 🗣️ toggle next to 🔊 on the title screen. Default: on once packs are cached, off before (never surprise-downloads). Enabling never bulk-downloads; first speaker's pack fetches on first use.
- **Fallback:** Web Speech API (device voice by sex, pitch/rate by age) when packs aren't cached or Piper fails.
- **System voice seam:** `Game.SYSTEM_VOICE_SEAM` reserved — ElevenLabs build-time asset, Claptrap-like per Steve 2026-10-11. Cost rule recorded: curate/approve ALL System lines BEFORE generating; never regenerate paid lines.
- Foreign-language beats are never voiced ("if you don't know, it doesn't show").
