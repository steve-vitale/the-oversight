# TITAN CLASS — evidence (2026-10-11)

Steve 2026-10-11: "Should we make titans for armies" — yes. This is the threat ladder that justifies the scale ladder.

## What was built

**`src/data/titans.json`** — the titan flag registry (deliberately NOT in `monsters.json`: the wave35-mechanics sibling worker owns that file mid-run; `Game.isTitan()` reads titans.json keyed by monster id). Three titans:
- **THE HERALD** (monster `eater`, wave 4) — the tutorial titan. It eats the GRID first: threatens the realm's FOOD, teaching the titan loop at low stakes. Its counter (poison the meal / starve the field) already exists. minAllies 2. Relic: *The Last Meal*.
- **THE MID** (monster `nielsen`, wave 5) — minAllies 3. Relic: *Dead Air*.
- **THE FINALE** (monster `finale`, wave 5, 1800–2200 HP) — the run's apocalypse. minAllies 4. Relic: *The Falling Title Card*.

Per-run cast: Herald + ONE apocalypse, seeded (high showmanship → Nielsen, else Finale). Never all three — scarcity is the point.

**`src/js/titans.js`** (`@ontology system: titans`) — the coalition-warfare module:
- **Flag, not HP**: `isTitan()` reads titans.json. `monsterWavePool` is wrapped — titans never wander; they arrive by omen only.
- **Hard gate, not stat check**: `startCombat` wrapped — a solo titan attempt is REFUSED aloud ("This is not courage. This is arithmetic."), never a likely death. Requires `titanMusterReady` (minAllies allied faces).
- **Omens** (dawn tick, guarded hook in game.js): stage 0 (something stirs, unnamed) → stage 1 (traders name it) → stage 2 (scouts find the lair, world monster placed). Knowledge-gated: no name before exposure. Ignoring it costs: every 5 days unanswered it raids your pantry (real kcal via `playerPackSpend`) or strikes an allied village (trust −5, said aloud).
- **War council** (played beat): leaders sit as faces via `theirSpeaker`, scout intel (honest, counter-hint only if known), System ODDS posted as entertainment — deliberately miscalibrated ("Our models have never seen a titan. Neither have you. This is fine.").
- **The call to arms**: allies answer with 2 named faces each, or REFUSE aloud with reasons (low trust / bad blood / arrears) — refusal costs trust −8 and is remembered.
- **Outfitting** (Steve's mechanic 1): `titanOutfit(villageId, itemIndexes)` — REAL items leave `scholar.inventory`, distributed across that force's fighters as real `wbonus`/`varmor` on their `kind:'ally'` combat fighters. The player sees what left and what it bought. Arming someone is SEEN — gossip telegraphs.
- **The turn** (Steve's mechanic 2): `titanTemptation(villageId)` = gear value / 80 + visible pack kcal / 1500 vs loyalty = trust + opinion/2 + 25. Verdicts: steadfast / watch / turn. The turn fires only when telegraphed (gossip warning was shown) — never random. When it fires: the force walks with the gear (loot law: LOST, no refunds), trust craters to 0, link history records the betrayal, said aloud as a played beat.
- **The player's contribution is LOGISTICS**: mustered allies eat 1000 kcal/day each from the player's stores; hunger erodes trust (−2/day/link) — an army marches on its stomach.
- **Fights are real**: allies inject as `kind:'ally'` fighters (100 HP, brave AI, real names, carried wbonus/varmor) into `tbfight.fighters` — the engine resolves them blow-by-blow. No RNG tables.
- **Deaths cost**: dead allies are marked dead in their home roster, link trust −10, speaker succession reuses the mirror beat, grief said aloud.
- **Victory**: 25% apex-relic roll (never a fountain), strategic drop (ledger entry, viewership bump, table-path/world-state), System televises it.
- **Defeat**: the titan remains, the muster breaks.

Integration: `game.js` fetches titans.json + one guarded dawn line (`titanDawnTick`) next to `podIntrusionTick`; `index.html` loads titans.js after pods.js.

## Design decisions (Steve can overrule)

1. **minAllies 2/3/4** (herald/mid/finale) — barely-survivable tutorial vs apocalypse.
2. **Allied fighter base 100 HP** — a real blade, not a hero; titans are won by coalition mass + outfitting + the counter, not by one NPC.
3. **Muster upkeep 1000 kcal/day/fighter** — the food-thesis payoff; hunger erodes trust rather than deserting (desertion is the turn's job).
4. **Temptation = gearValue/80 + packKcal/1500; loyalty = trust + opinion/2 + 25** — a well-outfitted force (6000 value) sits at ~75 temptation: safe at high trust, a loaded gun at low trust. The turn needs a prior gossip warning — no ambushes.
5. **Relic 25%, one roll, tier-4** — apex on its own terms, never a fountain. The strategic drop is the real prize.
6. **Herald = the Eater** (not the Finale as first titan): it eats the realm's food, so the tutorial titan teaches the loop at the food layer — Steve's core thesis. The Finale stays the apocalypse anchor.
7. **titanDefs() ignores `_`-prefixed keys** so titans.json can carry a `_comment` doc key.
