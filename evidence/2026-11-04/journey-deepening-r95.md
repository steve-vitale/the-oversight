## Metric review

- **Blocked-revisit flag is unreliable (instrument flaw, found this
  run):** 93802 day 60 logs Vasyl as `blocked` AND runs his revisit
  sitting (sittingLog revisit:true, transcript exists). Cause: the
  order helper unconditionally prepends the revisit target even when
  it failed the talkability pre-filter (dead / comm-none check), so
  a pre-filter miss is logged as blocked and then the sitting runs
  anyway. The transcript + sittingLog are authoritative; the blocked
  log must not be read as "no revisit happened." Fix candidate for
  the next run: only prepend the revisit target when it is in the
  talkable candidate list, and log blocked only when no sitting
  with that villager follows. No metric was re-scored on this: the
  B-FOLLOW bar counts sittings, and all three revisit sittings
  exist as transcripts.
- **Stay-repeat shape (r94 candidate, still open):** no sitting
  this panel pressed dlg:stay 4x (r94's shape did not recur), so no
  new evidence either way. A stay-rotation bound remains a
  candidate instrument refinement, not a game defect claim.
- **Declined-thing plants (open, not flagged):** two declines
  (Miguel, Stan) leave a pocketed thing never revisited in-window.
  The game never promises to reopen it; if a future run wants to
  judge whether declines should plant a revisit, that needs its own
