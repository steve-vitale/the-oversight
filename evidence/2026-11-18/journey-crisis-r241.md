## Fix 1: mime-walking variety (conversation.js)

**What the player saw.** A villager with no shared language invites
the scholar to walk with them by miming — and mimes the exact same
invitation, word for word, three days running (and again and again
after that). The meaning is right; the repetition is a person
repeating themselves like a recording.

**Root cause.** The walk-invitation mime was one hard-coded line in
the invite path. Every nonverbal villager served the identical
staging every time, with no memory of having mimed it before.

**Fix (src/js/conversation.js).** A pool of 6 mime variants — variant
0 is the original line verbatim, so the first mime in any run is
byte-identical to before. The pool rotates no-repeat-until-exhausted
per villager on the convo record, which persists across sittings.
Deterministic, no RNG draw (the TRAILTALK precedent, r236). Every
variant is stage direction, never quoted speech — the no-English rule
holds: they SHOW the invitation, they never say it.

**Proof test:**
`scripts/godpath/test-journey-crisis-r241-mimewalk-20261118.js` — **20/20
pass** on SEED=42 and SEED=7 (re-run in this adoption from the
godpath/ location; see the move note below). The test was authored at
`scripts/test-journey-crisis-r241-mimewalk-20261118.js` by the timed-out
run; this adoption moved it to `scripts/godpath/` (require path
`./godpath/lib` → `./lib` only) so `check.js --quick` enumerates it —
verified: `check.js --only mimewalk` reports 1 passed, 0 failed.

## Fix 2: Wren cache-note variety (alienPlayers.js + alienPlayers.json)

**What the player saw.** Wren's dead-drop note reprinted verbatim —
the same short note, 6 to 9 times on a single seed. Each drop is
supposed to be a new note left by a person on the run; the same words
every time read as a form letter.

**Root cause.** The cache note is the helpLines slot marked by
cacheNoteIndex, and the drop pick is uniform over 4 lines, so the
same note kept coming up — 9× on 14532, 6× on 14531, 7× on 14534
(and 5× on 14533). A drop leaves a NEW note each time; the code
never wrote a fresh one.

**Fix (src/js/alienPlayers.js + src/data/alienPlayers.json).** Six
cache-note variants in data (variant 0 = the original note verbatim),
rotated with a counter on the alien-player state
(`ap.cacheNoteIdx`). Deterministic, no new RNG draw, so the seeded
draw sequence is untouched. Only Wren carries cacheNoteIndex /
cacheNotes — other helpers are unaffected.

**Proof test:**
`scripts/godpath/test-journey-crisis-r241-wrennote-20261118.js` — **9/9
pass** on SEED=42 and SEED=7 (re-run in this adoption from the
godpath/ location). Moved from `scripts/` to `scripts/godpath/` in
this adoption for the same reason as the mime test (require path only);
verified: `check.js --only wrennote` reports 1 passed, 0 failed, and
`--only r241` reports 2 passed, 0 failed.
